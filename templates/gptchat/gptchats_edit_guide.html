Как начать работу с LLM

  1. Выберите провайдера. Для YandexGPT нужны OAuth-токен и Catalog ID, для OpenAI — API Key, для кастомного OpenAI-совместимого API — URL и ключ.
  2. Создайте чат на главной странице модуля и задайте ему название.
  3. Выберите модель. Новые модели предпочтительнее; устаревшие отмечены как deprecated и доступны только для чтения, пока вы не перейдёте на актуальную.
  4. Инструкция — это роль и правила для модели (например: «ты краткий помощник по погоде»).
  5. Запрос — конкретный вопрос. В него можно подставлять значения свойств: %Объект.свойство%.
  6. Температура — креативность: 0 — предсказуемо, 0.7–1 — более свободные формулировки.
  7. Связанное свойство — если заполнить, чат запускается автоматически при изменении этого свойства.
  8. Результат — можно обработать кодом и/или озвучить через терминал.
  9. История хранит все запросы и ответы; кнопка «Run now» позволяет повторить чат вручную.

Совет: начинайте с простой инструкции и одного запроса, затем добавляйте обработку результата.

Getting started with LLMs

  1. Choose a provider. YandexGPT needs an OAuth token and Catalog ID; OpenAI needs an API key; a custom OpenAI-compatible API needs a URL and key.
  2. Create a chat on the module's main page and give it a name.
  3. Pick a model. Prefer current models; deprecated ones are marked and read-only until you switch to a supported model.
  4. Instruction defines the role and rules, for example: "you are a concise weather assistant".
  5. Prompt is the actual question. You can insert property values like %Object.property%.
  6. Temperature controls creativity: 0 is deterministic, 0.7–1 gives more varied wording.
  7. Linked property makes the chat run automatically when that property changes.
  8. Result can be processed with code and/or spoken through a terminal.
  9. History stores requests and answers; "Run now" repeats the chat manually.

Tip: start with a short instruction and a single prompt, then add result processing.

Як почати роботу з LLM

  1. Виберіть провайдера. Для YandexGPT потрібні OAuth-токен і Catalog ID, для OpenAI — API Key, для власного OpenAI-сумісного API — URL і ключ.
  2. Створіть чат на головній сторінці модуля та задайте йому назву.
  3. Виберіть модель. Краще використовувати актуальні; застарілі позначені як deprecated і доступні лише для читання, доки ви не перейдете на нову.
  4. Інструкція — це роль і правила для моделі, наприклад: «ти короткий помічник з погоди».
  5. Запит — конкретне питання. У нього можна підставляти значення властивостей: %Об'єкт.властивість%.
  6. Температура — креативність: 0 — передбачувано, 0.7–1 — більш вільні формулювання.
  7. Пов'язана властивість — якщо заповнити, чат запускатиметься автоматично при зміні цієї властивості.
  8. Результат можна обробити кодом та/або озвучити через термінал.
  9. Історія зберігає запити й відповіді; кнопка «Run now» дозволяє повторити чат вручну.

Порада: почніть із короткої інструкції та одного запиту, потім додавайте обробку результату.
